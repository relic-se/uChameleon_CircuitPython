# μChameleon Pedal
CircuitPython guitar effects pedal based around the Raspberry Pi Pico 2 and the TLV320AIC3204.

## Hardware

This firmware is designed to be used with the latest version of [this hardware](https://github.com/relic-se/uChameleon_Hardware). If you would like to use your own hardware device, follow the pin mapping provided by the aforementioned repository.
